# Data

This directory holds the data files used by the analysis pipeline.
All files here are gitignored because they are either large downloads or
derived outputs that can be regenerated from those downloads.


## Source

NCBI Pathogen Detection, *Campylobacter* organism group.

Pinned release: **PDG000000003.2859**

This is the specific snapshot used to produce every number in the repository.
Using `latest_snps` instead would download a different version on each run
and make the results non-reproducible.


## Downloading the raw files

```bash
bash scripts/01_fetch_ncbi_metadata.sh
```

This fetches two files from the NCBI FTP server:

| File | URL path | Description |
|---|---|---|
| `PDG000000003.2859.metadata.tsv` | `Metadata/PDG000000003.2859.metadata.tsv` | Isolate metadata: assembly accessions, AST phenotypes, AMRFinderPlus genotypes, collection date, geography |
| `PDG000000003.2859.cluster_list.tsv` | `Clusters/PDG000000003.2859.reference_target.cluster_list.tsv` | SNP cluster assignments mapping assembly accessions to cluster IDs |

Base URL: `https://ftp.ncbi.nlm.nih.gov/pathogen/Results/Campylobacter/PDG000000003.2859/`

Downloads write through a `.part` file and only rename on completion, so an
interrupted download cannot be mistaken for a complete one.


## Columns used

From `metadata.tsv`:

| Column | Purpose |
|---|---|
| `target_acc` | Isolate identifier |
| `asm_acc` | Genome assembly accession, used to join with cluster assignments |
| `biosample_acc` | BioSample accession |
| `collection_date` | Date of sample collection |
| `geo_loc_name` | Geographic location |
| `isolation_source` | Source material (clinical, food, environmental) |
| `epi_type` | Epidemiological classification |
| `AST_phenotypes` | Laboratory susceptibility test results (the label) |
| `AMR_genotypes` | AMRFinderPlus gene calls (the features) |

From `cluster_list.tsv`:

| Column | Purpose |
|---|---|
| `PDS_acc` | SNP cluster identifier (renamed to `snp_cluster`) |
| `gencoll_acc` | Assembly accession (used for joining) |


## Filter sequence

The cohort is built by `scripts/02_build_cohort.py`:

1. Read all isolates from the metadata file (170,431 in this release).
2. Parse the `AST_phenotypes` field for the target drug. Retain isolates with a recorded S, I, or R call.
3. Of those, retain only isolates with a non-null `asm_acc` (genome assembly).
4. Left-join SNP cluster assignments on `asm_acc`. Isolates with no cluster assignment are kept and treated as singleton groups during splitting.
5. Assert no duplicate assembly accessions.

This produces:

| Drug | After step 2 | After step 3 (cohort) | No cluster |
|---|---|---|---|
| Ciprofloxacin | 4,002 | 3,984 | 464 |
| Tetracycline | 4,001 | 3,983 | 464 |


## Labels

The label is binary: `R` (resistant) maps to 1, `S` (susceptible) maps to 0.
Intermediate calls (`I`) are present in neither drug cohort in this release
but are flagged if they appear.

The label comes from `AST_phenotypes`, which records measured MIC or disk
diffusion results interpreted by clinical breakpoints. It does not come from
`AMR_genotypes`, which is the feature source. Using the genotype-derived
column as the label would make the target a deterministic function of the
input.


## Features

Features are built by `scripts/06_build_features.py`:

1. Split each isolate's `AMR_genotypes` string on commas to get individual gene entries.
2. Build a vocabulary of every distinct entry across the cohort.
3. Create a binary matrix: 1 if the isolate carries the entry, 0 otherwise.
4. Drop entries seen in fewer than `MIN_COUNT` isolates (default 3).

The default threshold of 3 retains 58 features for both drugs. The effect of
this threshold is tested explicitly by `scripts/10_threshold_sweep.py`.


## Directory structure

```
data/
  raw/          downloaded TSV files (gitignored)
  interim/      cohort parquet files, one per drug (gitignored)
  processed/    feature matrix, labels, fold assignments (gitignored)
```

All files can be regenerated by running the scripts in order.
